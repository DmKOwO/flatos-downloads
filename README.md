# FlatOS для Android

[Скачать FlatOS 0.1.0 APK](https://github.com/DmKOwO/flatos-downloads/releases/download/v0.1.0/FlatOS-0.1.0-debug.apk)

Android 8.0 и новее. Скачайте файл на телефон, откройте его и разрешите установку из браузера/файлового менеджера, если Android запросит это.

Первая рабочая debug-версия: ручные размеры, план квартиры, импорт PDF/изображений, фото стен и калибровка, кабели и трубы с точными координатами, проверки геометрии, документы, журнал и ZIP-резервные копии. Работает без интернета и регистрации.

[Описание выпуска и ограничения](https://github.com/DmKOwO/flatos-downloads/releases/tag/v0.1.0). [Фактическая проверка](https://github.com/DmKOwO/flatos-downloads/releases/download/v0.1.0/verification.md).

3D/AR, AI, OCR, отдельные каталоги устройств и полноценная нормативная экспертиза пока не реализованы. Проверка сверления не подтверждает безопасность. Неизвестные данные остаются неизвестными.

В этот репозиторий публикуются только установочные файлы, контрольные суммы и описание. Фотографии и проекты квартиры остаются на вашем телефоне. После важных изменений сохраняйте ZIP во вкладке «Файлы».
